NEXT (the ι cluster — the last Preservation obligation, the eliminator):

`preservation-ι` + the four literal-peel variants (`ι-nat-zero`/`ι-nat-suc`/
`ι-bounded-zero`/`ι-bounded-suc`). The obstruction is precise: the `brs∷`
rule types a branch body in `extendⁿ Γ ar`, whose field binders are
`tm-hole "field"`. The ι reduction substitutes the constructor's REAL args
(typed by `ctor-args ct`). The substitution lemma's coherence would need
`Γ ⊢ args_i ⇒ substS σ (tm-hole "field")`, which is absurd (nothing infers a
hole). So the field binders must be typed with `ctor-args ct`.

THE FIX (a typing-judgment change, rippling through the context machinery):

 1. Define `extendTele : ∀ {k} → Ctx k → Telescope → Ctx (length tele + k)`
    (cast-free, like `extendⁿ`):
       extendTele Γ []                 = Γ
       extendTele Γ ((nm , T) ∷ tele)  = extendTele (extend Γ T) tele
    so `extendTele Γ [A₁, A₂] = Γ ▷ A₁ ▷ A₂` (A₂ at index 0, A₁ at index 1),
    matching `branch-field-vars ar = [ar-1, …, 0]`.

 2. Change `brs∷`'s third premise from
       `extendⁿ Γ ar ⊢ b ⇐ tm-app (rename (λ j → j + ar) m) (tm-ctor cn (branch-field-vars ar))`
    to
       `extendTele Γ (ctor-args ct) ⊢ b ⇐ tm-app m (tm-ctor cn (branch-field-vars ar))`
    (the motive is no longer `rename (λ j → j + ar)`-weakened, because the
    field binders are now the real telescope, not extra holes).

 3. Rework the context lemmas (Proof/Context.agda): replace `extendⁿ`'s
    `lookup-extendⁿ-zero` / `lookup-extendⁿ-raise` with `extendTele`'s
    field/raise lookup laws, and replace `extF` / `lookup-extF` with a
    telescope-aware morphism. The field types are CLOSED (`ClosedSig`), so
    the raise law should be `refl`-level up to `rename (shiftRen k 0)`.

 4. Rework `ren-branches` / `subst-branches` / `conv-branches` and
    `coh-extendⁿ` → `coh-extendTele` (Proof/Preservation.agda) to use the
    new context. The branch body's field types are closed, so the coherence
    at a field position is `Γ ⊢ args_i ⇒ A_i` (from `⇒-ctor`'s spine).

 5. Prove `preservation-ι`: from `⇒-case ds dm dbrs` and the branch
    `(c, ar, b)`, `substArgs args b` checks `tm-app m (tm-ctor c args)` by
    the substitution lemma (the coherence maps field i to `args`), and
    `tm-app m (tm-ctor c args) ≈ tm-app m s` because `s = tm-ctor c args`.

 6. The four literal-peel variants additionally need the identification
